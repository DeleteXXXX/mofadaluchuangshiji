# 02 人物 · 主角与核心同伴

> 依据：001_序章_设定篇人物设定 + 正文出场统计 + 故事骨架/伏笔维度结论。原文未明确处均标注。

## 季天恒（主角）

| 项目 | 内容 |
| --- | --- |
| **种族** | 遗人族、精灵族、人族混血 |
| **年龄** | 001 写「十四岁」，003 母亲口「十五岁」——**原文矛盾，未统一** |
| **身份** | 身具遗人之力的少年；「光之主阿拉密斯」转生；亚里斯大陆新世纪创造者（创世） |
| **性格** | 自由散漫、不爱负责任；但过于善良热情 |
| **动机** | 早期只想找到哥哥混日子；后逐步接受救世/创世使命 |
| **弱点** | 无强者意识与心态；排斥被推上「创世」「光之主」位置 |
| **能力** | 遗人之力（额现神之眼、背后结光之翼，待魂之玉封印）；魔法、战技均习得 |
| **当前状态** | 第二部在格洛洲天使之晶城站稳脚跟：以云顶矿区水晶石为资本、办「季氏江湖菜」为据点、帮帕洛依·汉密尔顿夺护卫骑士一职，韬光养晦 |
| **成长弧光** | 被动卷入 → 接受使命 → 逃避「救世」帽子 → 为修达·梅承诺而战 → 把「重振亚里斯」从哥哥的理想变为自己的理想（091 转折） |
| **出处** | 001、003、006、019、033、050、057、091、104、112、119 等 |

## 修达·梅（导师，已逝）

| 项目 | 内容 |
| --- | --- |
| **种族** | 人族（五贤者之一） |
| **年龄** | 灭世之战前约 140 岁，与魔兽共享生命四百年 |
| **身份** | 天恒魔法启蒙导师，身兼火、雷魔法之长 |
| **性格** | 一代英杰，为救世耗尽一切 |
| **关键经历** | 灭世之战末役「人类的黄昏」后肉体失生机，与黑暗魔兽契约共享生命四百年寻救世之法 |

| **对主线影响** | 其「救世」遗愿是天恒长期动力；神之眼为其开启，是主角能力关键节点 |
| **出处** | 006–022 密集（019、021、022 为核心），后续仅回忆提及 |
