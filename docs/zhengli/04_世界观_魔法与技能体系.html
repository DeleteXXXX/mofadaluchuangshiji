《魔法大陆创世记—日出亚里斯》魔法与技能体系

以 002_序章二_技能设定篇 为基础，结合正文实际运用整理。原文未明确之处标注「原文未明确」。引用注明章节。

一、总分类：三大类

亚里斯时空的技能，根据力量的本源不同，分为三大类（见 002_序章二_技能设定篇）：

类别定义特点
战（武）技以爆发自身肉体力量作为战斗方式以肉体力量为基础
魔法技以精神力为基础产生各种攻击方式以精神力为基础
魔武合击技战（武）技与魔法技的结合魔武双修者少之又少，因两者练习都需极大努力，「与其两者都会，但却哪样都用不好，还不如只精于其中一种」（见 002_序章二）

二、魔法技的两大分支：魔法师技能 vs 术士的术

魔法技按力量来源不同，再分为魔法师技能与术士的术法（见 002_序章二）：

  • 魔法师技能：用自身的精神力做媒介，引发体外力量的技能。威力大小与精神力强弱以及对外界的认识息息相关。
  • 术士的术（术法）：将自身的精神力转变后施放出去，直接运用精神力并转变，形成各种不同的「术」。威力大小与精神力直接挂钩，转换方式也是重要影响因素。

两者难分优劣，但魔法师人员众多、术士人员稀少，因为成为术士首先必须是超能力者，能激发自身力量（见 002_序章二）。

原文未明确：002_序章二末尾 PS 明确写道「术士技能和战（武）技以后再补」，故术士的术的具体体系与战（武）技的体系设定在原文中并无系统展开，正文中亦无完整设定（详见《04_世界观_未解释设定.md》）。

三、元素魔法（六系）

元素魔法依据对自然界不同元素的调用，分为风、水、冰、火、雷、地六大分支（见 002_序章二）。

冰系独立：亚里斯大陆历 1067 年以前，水系与冰系同归水系魔法；1067 年后，由亚里斯第一位女性大魔导士弗朗西丝卡·摩多雅开创水系新高峰，将冰系分离为独立分支（见 002_序章二）。

系别定义攻/防特点原文补充
风系借助空气中风系元素的力量攻、防较为平衡高阶风系「飞行」魔法似乎失传；风舞九天属风系图谱上的传说姿态（见 065_第六十三章、060_第五十八章）
水系运用自然界中水的力量防御中等，攻击力低下，但治疗、回复能力极好天恒在云顶矿区初悟纯净水系元素（见 100_第二十七章、101_第二十八章）
冰系同样运用自然界的水，从水系分离攻、防俱佳，附加属性良好耗精神力多，施放预备时间为水系的三至四倍（见 002_序章二）；冰系见习魔法师「天生」出现（见 027_第二十五章）
火系运用自然界的热能重攻轻防，攻击力一流，防御力普通天恒的火球术威力直追高阶「流星火雨」（见 015_第十三章）
雷系运用自然界存在的电荷攻击力强，防御不差，但最耗精神力修达·梅「身兼火、雷魔法之长」（见 001_序章_设定篇）；精神力弱者与中级以下魔法师多不用（见 002_序章二）
地系（土系）借助大地的力量攻击力中上，防御力超高，是最好的防御魔法，且具良好回复属性正文中未见具体运用（原文未明确更多）

注：006_第四章中修达·梅归纳「七类」为风、水、火、土、光、暗、召唤，与 002 的六系口径（土/地为同一系）基本对应。

四、生灵魔法

  • 定义：一些与大自然亲密生活、成为大自然一部分的种族，以精神力为温床、动/植物胚胎为凭依，用精神力抚育胚胎成长，形成具有独特性质的动、植物变体，辅助自身做事或参战（见 002_序章二）。
  • 分类：分为动物系与植物系两类。
  • 代表种族：
  • 植物系：住在森林里的妖精（见 002_序章二）。
  • 动物系：居住在依修斯大陆东北部的半服洛族（见 002_序章二）。
  • 正文实际运用：
  • 嘟嘟儿的生灵魔法「萝叶青藤」（见 067_第六十五章_妖精之塔）。
  • 嘟嘟儿将三个「桔香铃兰结」放在地面，施放生灵魔法（见 072_第七十章_相会(上)）。
  • 嘟嘟儿「以百发百中的箭法和生灵魔法而见长」（见 001_序章_设定篇）。

五、光明魔法

  • 定义：原为神族独有力量为依附才能施展的魔法，拥有超强的攻、防能力和一些极为复杂的特殊能力（见 002_序章二）。
  • 流传：神魔大战后，因不明原因渐渐流传到人族魔法师中，小范围流传，高级魔法学院的毕业生和一些神秘人士也会一些初级光明魔法（见 002_序章二）。
  • 正文实际运用：
  • 帕洛依·汉密尔顿「拜入圣骑士拉雷门下，会神圣的光系魔法」（见 108_第三十五章）。
  • 天恒在第三十八章被问及「枪尖的白光是神圣的光系魔法么」（见 111_第三十八章）。
  • 依丽娜·千达会强力的水系和光系魔法（见 001_序章_设定篇）。
  • 天恒的「光之翼」「神之眼」发出的圣洁之光，与神族形态相关（见 022_第二十章、056_第五十四章）。

六、黑暗魔法

  • 定义：与光明魔法相似，必须是具有黑暗力量的魔族才可能施展，本是魔族的看家技能（见 002_序章二）。
  • 遗传特点：神魔大战后，偶有魔族与人族及他族通婚，后代具有微弱黑暗力量；但黑暗力量遗传方式独特，不直接传给下一代，而是「超隔代大遗传」，在后代许多代中随机出现。
  • 获得条件：这种力量的获得必须经过死后重生才能得到，故拥有黑暗力量的人不多；且「生而後生」，即使身负黑暗之力，主人往往自己并不知道（见 002_序章二）。
  • 正文实际运用：
  • 修达·梅与黑暗的不死魔兽依娜定下契约，共享其不死生命；身体逐渐腐烂、灵魂走向黑暗，并无师自通了禁忌血咒「同化」（见 022_第二十章）。
  • 黑暗力量相关的情节在 008、009、012、017、018、022、051、056、059、063、064、082、089—097、100—105、109 等多章出现（多为氛围或角色背景，未形成系统设定）。

七、召唤魔法

  • 定义：通过自身精神力，借助魔法阵和其它媒介，同非生命体建立契约，召唤出它们以获得帮助（见 002_序章二）。
  • 召唤物：通常包括魔兽、神兽、精灵等；强力召唤魔法师甚至可以召唤强如龙的超强魔法生物。
  • 优缺点：施法者本人通常不参与战斗，只凭召唤物作战——安全而威力大；但施法者必须用魔力维持与召唤物的联系，自身成为拖累、易成攻击目标。好坏取决于召唤者素质与召唤物能力（见 002_序章二）。
  • 正文实际运用：
  • 天恒与元素精灵丁多强行建立契约（见 037_第三十五章_精灵）。
  • 天恒曾召唤/孵化龙蛋，用神之眼圣光照射（见 056_第五十四章）。
  • 41 章出现与「召唤」相关内容（见 114_第四十一章）。

八、血咒

  • 定义：黑暗魔法与术士的术结合后的独立产物，是二者的旁系分支（见 002_序章二）。
  • 原理：以精神力为基础，以施法者自身血液为媒介，燃烧生命力，施放出远超自身能力许多倍的魔法力量。
  • 特点：威力通常超大，但必须以自身生命为代价，是自杀式魔法；除威力强劲外，还具有同化、溶合、支配等独特功能（见 002_序章二）。
  • 正文实际运用：
  • 修达·梅施展禁忌血咒「同化」——本为黑暗生物呼唤亡灵同化为作战伙伴所用，他无师自通（见 022_第二十章）。
  • 修达·梅与黑暗魔兽定下契约亦涉血咒（见 022_第二十章）。
  • 血咒关键词另见于 006_第四章、022_第二十章。

九、太古魔法

  • 定义：严格来说已超出传统魔法范畴，是魔法技能与神、魔辉煌时期的高科技文明结合的产物，通常以遗物上所具有的特异能力表现出来（见 002_序章二）。
  • 现状：神魔大战后失传，几乎只能在历史书与魔法图鉴上看到；遗物几乎被破坏殆尽，只在恢复生机后的亚里斯大陆上留下稀少的遗迹（见 002_序章二）。
  • 正文实际运用：
  • 费尔多城堡的魔法巨炮是太古魔法遗物之一例（见 002_序章二、026_第二十四章、027_第二十五章）。
  • 凯普斯所留的太古魔法手札（见 100_第二十七章）。
  • 矮人炮弹：矮人族采用特殊工艺并配合太古魔法制成，原为神魔大战时矮人族制作、交由人族对付魔族的利器，威力巨大且小巧易携带（见 105_第三十二章注①）。
  • 太古魔法关键词另见于 006_第四章、021_第十九章、098_第二十五章、099_第二十六章。

  • 亚里斯本土战技：豹人族的本能战技（抓、咬等，被天恒评价「破绽百出」）（见 001_序章_设定篇、021_第十九章）。
  • 战技与斗气、内息：文中「内息」与「斗气」常被等同（天恒称「内息斗气也差不太多」），原文 089_第十六章。武者的丹田是施展武技的力量来源，魔法师的眉心是精神力汇集地（见 007_第五章）。

十一、魔武合击

  • 定义：战（武）技与魔法技结合（见 002_序章二）。
  • 正文实际运用：
  • 天恒在塔拉姆防守战中尝试魔武合击：「一边用普罗拉西奥拔打着标枪，一边分神凝集火元素，一身的魔力和内息都在运行」，但「两头都想顾，却两边都顾不上」（见 077_第四章）。
  • 天恒最终在突围中「真正的初悟到魔武合击的奥妙，开辟了将魔法和战技相揉合的新路子」（见 103_第三十章）。

十二、施法方式

  • 传统方式：吟唱祭文（言灵）：魔法师大多通过言灵激发魔力、借用大自然力量，需吟唱具有言灵的祭文，与外界能量共鸣。威力越大，所需祭文篇幅越可观；对祭文的熟练程度极大影响战斗力，故魔法师普遍记忆力强、口齿伶俐（见 012_第十章）。
  • 印结：由基德·唐·克鲁曼十九岁所创，借助手形的变换代替冗长吟唱，开辟了魔法施法新途径；后基德于四百九十二岁成为不用吟唱、结印施法的第一人（见 001_序章_设定篇、042_第四十章）。修达·梅亦会此术，并传授天恒、扎克（见 012_第十章）。
  • 契约：通过与众神/非生命体等建立契约来使用力量，是魔法与召唤等技能的重要媒介（见 006_第四章、037_第三十五章、002_序章二）。

十三、其它力量概念

  • 内息：天恒体内的力量体系，可外爆、可内爆，亦可与魔法、遗人之力结合（见 036_第三十四章、011_第九章、013_第十一章）。
  • 斗气：亚里斯武者的力量（与天恒的「内息」相近，见 089_第十六章、024_第二十二章）。
  • 小宇宙：天恒体内以「思维」为核心的力量空间，遗人之力、内息、眉心力量团在其中关联（见 007_第五章、013_第十一章）。
  • 遗人之力：天恒作为遗人族的特殊力量，可被唤醒、运转，与光之翼、神之眼等神族形态相关（见 009_第七章、022_第二十章、056_第五十四章）。

十四、体系小结

亚里斯技能体系呈现「战（武）技 / 魔法技 / 魔武合击技」三大类骨架，魔法技内又分魔法师技能（引体外之力）与术士的术（直接转变精神力），并按来源细分为元素六系、生灵、光明、黑暗、召唤、血咒、太古七大类。其中太古魔法已失传、术士的术与战（武）技体系未系统展开，是原文设定中的主要留白。
